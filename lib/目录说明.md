## 分层架构说明

整体数据流：
```
用户操作 → features（业务页面）→ providers（状态管理）→ repositories（业务接口）→ sources（数据来源）→ Hive/API
```

---

## 目录分类依据

### 一、app/ — 应用级配置
**分类依据**：存放整个应用的全局配置，与具体业务无关。

| 文件 | 用途 |
|------|------|
| `app.dart` | MaterialApp 根组件，路由和主题配置 |
| `router.dart` | GoRouter 路由定义 |
| `theme.dart` | Material Design 3 主题配置 |
| `constants.dart` | 应用级常量（APP_NAME、API_URL等） |

---

### 二、core/ — 基础设施层
**分类依据**：项目基础能力，与业务无关，任何模块都可调用。

#### 2.1 network/ — 网络层
| 文件 | 用途 |
|------|------|
| `dio_client.dart` | Dio 实例创建和配置 |
| `interceptors.dart` | 请求/响应拦截器（Token、错误处理） |
| `api_exception.dart` | 统一网络异常定义 |

#### 2.2 storage/ — 本地存储
| 文件 | 用途 |
|------|------|
| `hive_service.dart` | Hive 初始化和 Box 管理 |
| `storage_keys.dart` | Hive Key 常量定义 |

#### 2.3 utils/ — 工具类
**分类依据**：纯函数工具，无副作用，可独立测试。

| 文件 | 用途 |
|------|------|
| `sm2_algorithm.dart` | SM-2 记忆曲线算法 |
| `date_utils.dart` | 日期计算和格式化 |
| `validator.dart` | 输入验证（用户名、密码等） |

#### 2.4 logger/ — 日志
| 文件 | 用途 |
|------|------|
| `logger.dart` | 统一日志封装（Debug模式输出，Release模式关闭） |

#### 2.5 constants/ — 常量
| 文件 | 用途 |
|------|------|
| `app_colors.dart` | 颜色常量 |
| `dimens.dart` | 尺寸和间距常量 |

---

### 三、data/ — 数据层
**分类依据**：管理数据模型和数据访问，实现数据与业务解耦。

#### 3.1 models/ — 数据模型
**分类依据**：定义业务数据结构，用于 Hive 存储和 API 响应解析。

| 文件 | 用途 |
|------|------|
| `word_model.dart` | 单词数据（英文、音标、释义、例句） |
| `word_status_model.dart` | 单词学习状态（熟练度、下次复习时间） |
| `word_book_model.dart` | 词库数据（名称、ID） |
| `user_model.dart` | 用户数据（信息、Token） |
| `study_record_model.dart` | 学习记录（时间、数量、正确率） |

#### 3.2 repositories/ — 仓库层
**分类依据**：业务数据接口，页面只调用 Repository，不关心数据来源。

| 文件 | 用途 |
|------|------|
| `word_repository.dart` | 单词数据操作 |
| `study_repository.dart` | 学习记录操作 |
| `user_repository.dart` | 用户数据操作 |
| `ai_repository.dart` | AI 接口调用 |

#### 3.3 sources/ — 数据源
**分类依据**：真正访问数据的位置，分为本地和远程。

##### local/ — 本地数据源
| 文件 | 用途 |
|------|------|
| `hive_word_source.dart` | Hive 单词读写 |
| `hive_record_source.dart` | Hive 学习记录读写 |

##### remote/ — 远程数据源
| 文件 | 用途 |
|------|------|
| `auth_api.dart` | 登录/注册接口 |
| `word_api.dart` | 单词相关接口 |
| `sync_api.dart` | 数据同步接口 |

---

### 四、providers/ — 全局状态管理
**分类依据**：Riverpod 全局状态，跨页面共享的数据。

| 文件 | 用途 |
|------|------|
| `user_provider.dart` | 用户状态（登录信息、Token） |
| `word_provider.dart` | 单词状态（当前学习单词） |
| `study_provider.dart` | 学习状态（今日任务、进度） |
| `theme_provider.dart` | 主题状态（暗黑模式切换） |

---

### 五、features/ — 业务功能模块
**分类依据**：按业务功能模块化，每个 feature 内部独立。

#### Feature 内部结构规范
| 子目录 | 用途 | 是否必需 |
|--------|------|---------|
| `pages/` | 页面 Widget | ✅ 必需 |
| `controller/` | 页面状态管理（StateNotifier） | ✅ 必需（有状态时） |
| `widgets/` | 页面专用组件 | ❌ 可选（只有多组件时） |

#### 5.1 splash/ — 启动页
**用途**：App 启动、判断登录状态、初始化

#### 5.2 auth/ — 用户认证
**用途**：登录、注册、密码找回

#### 5.3 home/ — 首页
**用途**：展示今日任务、学习统计、快速入口

#### 5.4 learning/ — 核心学习（重点模块）
**用途**：单词展示、发音、释义、用户反馈（认识/模糊/不认识）

#### 5.5 review/ — 复习模块
**用途**：根据 SM-2 算法生成复习任务

#### 5.6 vocabulary/ — 词库管理
**用途**：查看词库、创建词库、添加单词

#### 5.7 practice/ — 练习模式
**用途**：选择题、拼写、听音辨词三种模式

#### 5.8 ai/ — AI 辅助学习
**用途**：AI 助记、词根解释、流式输出

#### 5.9 statistics/ — 数据统计
**用途**：学习趋势图、热力图、统计卡片

#### 5.10 profile/ — 个人中心
**用途**：用户信息、设置、数据同步

---

### 六、components/ — 通用UI组件
**分类依据**：被两个以上页面引用的公共组件。

| 文件 | 用途 |
|------|------|
| `common_button.dart` | 统一按钮样式 |
| `loading_view.dart` | 加载状态 |
| `empty_view.dart` | 空数据状态 |
| `error_view.dart` | 错误状态 |

## 黄金法则

1. **不要提前抽象**：组件/逻辑只在一个页面用，就放在对应 feature 内
2. **按需抽取**：被 2 个以上页面引用时，抽到 `components/` 或 `core/utils/`
3. **分层单向依赖**：features → providers → repositories → sources → Hive/API
4. **Feature 内聚**：相关代码尽量放在同一个 feature 目录下
